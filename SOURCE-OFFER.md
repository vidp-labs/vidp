# Vidp Corresponding-Source Offer

Md Mostafijur Rahman, as the copyright holder of the Vidp project, offers to
provide the complete corresponding source code for the GPL-licensed and
LGPL-licensed components included in any Vidp release that contains this
notice.

This offer remains valid for at least three years after the date the applicable
release was last distributed. The source will be provided to any
recipient of that release who makes a written request through the Vidp issue
tracker:

<https://github.com/vidp-labs/vidp/issues>

Please include the exact Vidp release version and the component source being
requested. The source offer covers the corresponding source required by the
applicable GPL or LGPL license, including the source needed to build the
distributed component versions. The component license texts and upstream
project links are listed in [LICENSES.md](LICENSES.md).

Vidp's own source and build scripts are available in this repository at the
matching release tag.
